# The-Effects-Of-Nudging-On-Auditory-Decision-Making
Three-experiment study of nudging in auditory decision-making under perceptual uncertainty. Experiment 1 validates difficulty using detection of a 1000 Hz tone in Gaussian white noise across SNRs; Experiment 2 tests behavioural nudge effects online; Experiment 3 conditionally examines pupil dilation in the laboratory.
